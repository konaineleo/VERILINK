Check Before You Click.

VERIKLIK looks for phishing and malicious-link warning signs in a web address without ever visiting it. Links clicked with the VERIKLIK extension arrive here and are checked automatically.

      How it works

      The backend parses the URL text and scores independent signals: IP-address hosts, embedded user information, punycode, brand names in misleading subdomains, many subdomains, unusual ports, very long or double-encoded URLs, and plain HTTP. Points add up to a 0–100 score: 0–19 Low Risk, 20–49 Suspicious, 50–100 High Risk. No signal is proof on its own.

      Security limitations

      This is a heuristic baseline, not a machine-learning model. Threat-intelligence lookups are not configured, so known-malicious links are not detected. Page content and domain age are never checked. “Low Risk” means no warning signs in the address, not that the site is safe.

      Privacy

      Only the URL text is sent to the VERIKLIK API. It is never opened or fetched. The extension passes the link in the address bar of this page, so it can appear in your browser history; the page removes it from the address bar after reading it. Choosing Direct sends nothing.
